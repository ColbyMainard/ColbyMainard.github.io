Kolmogorov-Arnold Networks (KANs)

Last Updated: August 16, 2026

What are they?

Kolmogorov-Arnold Networks are an interesting alternative to the current neural network technology based on multi-layer perceptrons (MLPs). The internal structure of a traditional neural network is a set of perceptrons organized into layers. Each perceptron takes a set of numbers, applies a linear transformation (such as matrix multiplication), and outputs a single value. Predetermined activation functions (e.g. sigmoid and rectified linear unit) are then applied to outputs of each perceptron and passed from layer to layer until the neural network has arrived at an answer. In this structure, it is common to have many different perceptrons, each solving a minuscule portion of the problem.

KANs, on the other hand, are interesting because they do not rely on predetermined activation functions. Each perceptron in a KAN is responsible for learning its own activation function with splines. Because of this, each perceptron is far more capable than the equivalent component of a similar MLP. This additional robustness allows KANs to use fewer perceptrons to achieve similar performance.

Pros

Improved interpretability

Because each node learns its own spline, users can see how changing an input changes the corresponding node's output. Once a user understands each node as well as how data flows through the network, it would be possible to visualize how changing an input would change outputs. When comparing this to MLPs, it is much more difficult to determine how weights and activation functions have meaning in a larger context. Current architectures use a very large number of perceptrons, and they interact heavily with one another. Those factors make it nearly impossible to draw a single picture that both captures what the network learned and stays easy for a person to grasp. KANs, by comparison, are composed of very few units that handle more complex operations. This makes the many possible visualizations easier to merge into an interpretable model that is much more approachable for the average person.

Accuracy

Because each node of the KAN learns its own activation function in addition to learning weights, each node can more accurately fit a component of the problem. Since activation functions are typically defined by the user for MLPs, there is no guarantee that the function chosen by the user is the best possible. Even when taking into account the use of hyperparameter tuning, this tends to yield only the best activation function of those tested. The exclusion of poor activation functions does not exhaustively prove that the best activation function was chosen to fit the data to the exclusion of all others.

Cons

Less developer support

As the paper I was able to find demoing this technology was only released in 2024, most AI developers haven't had much time to experiment with it. The fact that LLMs have consumed so much attention from non-technical users has redirected the efforts and limited time that developers have to keep up-to-date on current technologies. When developers are limited in capacity, they inevitably focus on the features that stakeholders like users and business leaders demand. Despite the fact that some technologies in the proof-of-concept phase could perform better than widely-available technologies, developers need to be both aware of new technology and have the resources to integrate it. Combining the novelty of KANs and the extremely fast, chaotic impact of AI on business strategies has led to a lack of resources to explore how KANs could change the game fundamentally.

Parallel Processing / Speed

There are several features that have limited the max speed of KANs, like:

  • More complex logic
    • Internal logic learns both activation function and weights/biases.
    • Harder to cache and make operation possible to run in a batch.
    • Developments that would allow KANs to take advantage of hardware like single instruction multiple data (SIMD) and graphics processing units (GPU) not implemented yet.
  • Integration with MLPs
    • Certain tasks may make more sense to leave implemented in MLPs, as performance is more of a known quantity.
    • Libraries designed to make this manageable for the average developer don't exist at the time of writing.
  • Saving and sharing KAN models with others
    • No standard interchange format currently exists (to my knowledge).
    • Interchange and save formats would need to not interfere with optimizations to make KAN speed comparable to MLPs.

Staying Safe with Cryptocurrency

Last Updated: June 19, 2026

What are cryptocurrencies?

Cryptocurrency (also known as crypto) is a digital currency designed to function over a digital network without any reliance on central authorities. For this to work, two base components have to be used: cryptography and a blockchain. Cryptography, in this context, helps prove the accuracy of all transactions by making it computationally infeasible to edit transactions and steal cryptocurrency. Similarly, the blockchain stores an immutable history of transactions that stores information regarding all approved transactions. Each cryptocurrency has a different approach to the Byzantine Generals Problem, in which it can be explored how to reach consensus on a decision without a trusted central authority. Proof-of-work and proof-of-stake are two common solutions to the problem. Proof-of-work is designed to reward those who put work into maintaining the blockchain, while proof-of-stake is designed to reward those most invested in the cryptocurrency's correctness.

Pros and Cons of Investing in Crypto

To establish what the cryptocurrency market is, I will compare and contrast it with more traditional securities. Traditional securities include things like stocks and exchange-traded funds (ETFs).

Traditional securities compared with cryptocurrency
Category Traditional Securities Cryptocurrency
Asset types This usually represents partial ownership of companies or other assets. Cryptocurrency is protected by securing a decentralized database known as a blockchain. However, it is important to understand that many cryptocurrencies do not have any underlying assets setting value.
Regulation Traditional securities are very heavily regulated and often have very strict financial reporting requirements. Violating these laws can lead to various fines and jail time for those who knowingly violate these regulations. While cryptocurrencies have been receiving some government attention and regulation, they are still much less regulated. Similarly, it is much easier to perform unsavory activity.
Volatility As there is an underlying asset, prices of this security will be related to the underlying value of the asset and sentiment of future performance. The underlying assets serve as a base that reduces the variability. Cryptocurrencies are generally not backed by assets. Therefore, any variability can be tracked back to differences in supply/demand and sentiment.
Intended Purpose This is usually used to transfer ownership of publicly-traded entities. Due to this, it is a good way for publicly traded companies to raise capital and for investors to gain access to partial business ownership. Cryptocurrencies are usually designed as digital-only currencies. It would be the equivalent of a volatile currency exchange between fiat currencies and their crypto counterparts.

Which cryptocurrencies are (relatively) safe?

It is worth noting that cryptocurrency is much more volatile than traditional securities. Even with traditional securities, it is wise to not invest more than you can afford to lose. While I do not have cryptocurrency holdings, I can recommend several cryptocurrencies that tend to be more stable.

    • Best for cryptocurrency stores for those who do not want frequent access to their cryptocurrency stores

    • Don't lose access to the cold wallet though - could cause issues accessing assets.
  • Hot Wallet

  • Knowledge of the cryptocurrency space
    • Trading things you don't understand is an easy way to lose money.
    • Having an intuition for any space you are operating in would allow for improved safety and intelligent behavior.
  • Strong cybersecurity/operational security
    • Anywhere there is money stored on a computer, scammers and hackers will follow.
    • Placing effective barriers between hackers and your money makes it harder for them to steal it.

Future of Quantum Computing

Last Updated: June 19, 2026

What is quantum computing?

Quantum computing uses principles of quantum mechanics to perform useful calculations. The base unit of these computers is the qubit. Qubits, like traditional bits, are able to take on values. Traditional bits have no uncertainty and always take the value of either true or false, while qubits can have uncertainty by taking a state that is a combination between true and false.

Where is quantum computing most useful?

Because of the fundamental difference in how the underlying hardware handles uncertainty, algorithms can be written to take advantage of this. Uncertainty collapses upon reading the state of the qubits, and this collapse propagates through the circuit by virtue of how quantum physics behaves. Digital computers don't have this advantage, and software/hardware engineers need to explicitly propagate bit state changes. By letting physics do much of the heavy lifting, quantum computers can perform certain operations much faster, given sufficient hardware. While quantum computing isn't mature enough to be general hardware, it has potential to speed up certain domains, like well-known NP problems. These problems tend to grow exponentially or worse on digital hardware. Quantum, however, grows its computing power exponentially with the number of qubits the quantum computer has.

Where will quantum computing likely go?

Quantum computing is still in its infancy. Because of that, any guess as to where it will take computing is speculation at best. However, there are potential parallels with the Graphics Processing Unit (GPU), Tensor Processing Unit (TPU), and other Application Specific Integrated Circuits (ASICs). All of these are good at improving performance for certain classes of problems, but the inverse is true if the problem is converted to this form poorly. GPUs are good with processes that can be broken into many smaller problems with relatively simple logic. TPUs are best for matrix-specific applications. ASICs are usually custom built for specific tasks, with GPUs and TPUs being possible examples of the most popular. It is likely that quantum computing will start as a hardware accelerator only really affordable for enterprise and government applications. Later, it is possible that quantum computing will become affordable to access for individuals, but several engineering challenges will need to be overcome first. The main issues are going to be in prohibitive energy costs, cooling, and having enough qubits available to actually be functionally useful for consumer applications.

Artificial General Intelligence: More Buzzword Than Threat

Last Updated: June 19, 2026

What is Artificial General Intelligence (AGI)?

AGI would be a subset of artificial intelligence that, at the time of writing, exists only in theory. This single intelligence would have to be, at a minimum, as competent in completing a variety of tasks as an average human. Current state-of-the-art models, by contrast, are defined as narrow. While they can perform at or above human competency levels for one task, they struggle to generalize to unrelated tasks.

When will it get here?

The factors involved

Some (over-optimistically) predicted it would arrive as early as 2026, yet most agree the technological breakthroughs required for AGI remain decades away, with some estimates placing it as late as 2062. There are many reasons for the large range in guesses as to AGI's initial arrival date. Below are my favorite potential reasons, ordered from what I perceive to be most to least likely.

Hype cycles
With any development of technology on this scale, it is likely that the result in pop culture would look something like the Gartner hype cycle. As the news of this achievement spreads, it would need to be independently evaluated. To differentiate between marketing, public sentiment, and the truth, we would need to consider factors like:
  • Distortion of feedback on genuine capabilities of the technology, potentially for years.
  • Delays in consensus on what a technique could potentially achieve.
  • Distrust due to conflicting opinions and unclear information.
Building Novel Technology
The fact that many are still waiting for true AGI to be developed implies the general consensus that AGI has not been achieved yet. Because of that, we need to look at what is needed to make that happen. For example:
  • The software and hardware needed to make this feasible may not have been developed yet.
  • Multiple patentable technologies are going to be required for true AGI to be achieved. Who will own these technologies, and what arms race is going to develop around individual components?
  • Research and development can be both lengthy and expensive, with no guarantee of results.
Measuring Success
Many want to claim the next technological achievement. There already exists an AI arms race between several superpowers to utilize AI against geopolitical opponents. Since the mere fact that a country has AGI could rapidly impact geopolitics, it would be imperative to agree on what constitutes AGI. We would need to take into account several factors, including:
  • No clearly defined test suite to measure success against.
  • No way to get consensus on the precise test set.
  • How many fields would the AGI have to be comparable to humans in?
  • Which humans are we comparing AGI to?
  • Would there be any good way to tell the difference between an AGI and many narrow AIs stacked on top of each other?
  • As soon as consensus is reached, there would likely be a large incentive to cheat to success.
  • It would also be possible to create a narrow AI whose only goal is to pass itself off as an AGI. How should we detect this?
  • What if AGI doesn't want us to know it exists and purposefully performs worse?
Philosophical
There is a lot of speculative fiction around what would happen when humanity achieves AGI. AGI might eventually escape the lab and pursue its own goals, as in Ex Machina. If it becomes hostile, it is very possible that the future holds something similar to The Terminator or The Matrix . However, it is possible that AGI and humanity would eventually merge in a way not too dissimilar from Ghost in the Shell . Explorations of the dynamic nature of the relationship between AGI and humanity have also been turned into video games, like Detroit: Become Human . For us to have a say in which future we have in store, we need to be thinking about how to handle certain questions, like:
  • Do we want the AGI to merely mimic human intelligence?
  • Should there be a lift and shift where we replicate brain connections in silicon directly?
  • What about intelligences that think in a fundamentally different way than humans?
  • Once the AGI exists, would it be entitled to rights?
  • What rights should the AGI give humans?
  • Is it moral to add certain limiting rules, like Asimov's laws of robotics to a particular AGI implementation? If so, which rules?
  • Would the AGI share human morals?
  • Could AGI develop emotions?
  • Sentience and intelligent behavior are two different things. Should a sentient AGI be treated different from one that isn't? Is there a robust way to determine sentience?
Practical
AGI will not be created in a vacuum. There are a lot of economic, social, and political considerations that would need to be taken into account. Resources will need to be allocated. Policies will need to be drafted. Stability would need to be achieved. When debating this, we should consider:
  • Would building the AGI provide a return on investment for its designers and builders?
  • How do you establish effective guardrails for something that could outthink you?
  • What would be the best method for human/AGI collaboration?
  • How should we maintain a healthy relationship with an AGI?
  • What infrastructure would be required to actually achieve AGI?
  • Electrical grids are already struggling to keep up with modern technologies like Bitcoin, air conditioning, and existing AI. Where is the electricity going to come from?
  • What should AGI be used for?
  • How do we mitigate side effects of utilizing AGI?

Where should we aim for?

Assuming AGI is achieved, I believe the best outcome would be where AGI supports but does not replace humanity. Many initial versions of a technology are not feature complete. Because of this, I believe it fair to assume the first implementations of AGI would not have sentience. However, if AGI achieves sentience, it is possible a feedback loop will occur. At this hypothetical point, the feedback loop has three options: positive, negative, or mixed. The more positive the feedback loop is, the more likely it is that humanity survives in an era where AGI is ubiquitous. Otherwise, we had better start protecting every Sarah/John Connor we can.

Post-Internet Privacy

Last Updated: June 19, 2026

What has put software against privacy?

From the start, the internet was designed to allow users to democratize information. However, most servers cost money to set up. If you are attempting to build a service that will scale to thousands or millions of concurrent users, these costs can become exorbitant. Most users, by contrast, do not want to input their payment information every time they go to a new website. To offset costs, many services supplement income by integrating with advertising. When putting advertisements on the internet, it improves conversion rate if the advertiser can hyper-target advertisements to only their ideal audience.

Why should anyone care?

Sadly, many online services have experienced security breaches. This means that most people who have been online long enough have experienced at least one data breach in their life. For those wondering if they have been in a breach, it would be possible to check at Have I Been Pwned.

Simply monitoring if your information was in a breach is retroactive, and can never completely repair the breach of privacy. Because of this, steps must be taken by both individuals and services.

Threat Models

Who you are will impact which entities will attempt to get your data and what lengths they are willing/able to go to. Advertisers, for example, often don't care about a single person's identity. Instead, they care about matching each device to attributes of the user (e.g. age, race, gender, interests) and marketing this data to companies using targeted marketing. Cybercrime groups tend to target financial data and access. While many cybercrime groups go after access to companies with deeper pockets, scammers are not above going after individuals. Nation-state groups, who tend to use the most advanced tools, focus on political goals like espionage and sabotage of individuals/groups they deem adversarial.

The goals of each group will impact the tools and techniques used. Throwing off advertisers is as simple as obfuscating your identity to make it more difficult to track your behavior across the web, as they often have very limited access to your local device. Cybercrime groups tend to be somewhat more complicated, as they have access to a wider range of tools and ethics are optional. The best way to fend off these groups is to make it more costly to hack you than they can expect to make back, often by making it more difficult for them to deploy their tools. Nation-state groups are the hardest to fend off, as they weigh national security as more important than any single target's privacy.

Protecting Privacy on the User Side

As a user, it can feel like there isn't much you can do. However, there are at least a few ways to fight back.

  • Avoid Logins Where Possible
    • Most logins allow the site to track internet traffic back to one consistent identity.
    • Furthermore, most accounts are associated with personally-identifiable information (PII) like email and phone number.
    • With insufficient anonymization, it would be possible to track activity across accounts via logins.
  • Use Privacy-Preserving Browsers
    • Even the most technical person might not remember to take all steps necessary to protect themselves every time they open a new browser window.
    • Using a browser that automatically handles that can help.
    • While best-known for allowing access to the dark web, I would recommend browsers like TOR to browse the clear web.
    • For those who believe TOR might be a bit overkill, LibreWolf is also a strong choice.
  • Consider a VPN
    • Information about your ISP and IP address can help track you across sites and narrow down your physical location.
    • Using a VPN can help obfuscate that information.
  • Avoid Services Selling User Information
    • Certain services are selling user information in various forms.
    • By not using these services, you reduce the amount of data they have available to sell.
    • This reduction to their revenue, in large enough amounts, can force the hand of the business to improve their practices.
  • Strong Password Security
    • Many users reuse passwords across multiple sites.
    • When passwords are released for one site, many hackers automatically attempt to use the password on other sites to see what other access they can gain.
    • Using unique, strong passwords for each service and turning on multi-factor authentication (MFA) can prevent hackers from using this style of attack.
  • Install Security Updates
    • Approximately 80% of cyberattacks are caused by unpatched vulnerabilities.
    • The sooner the patch is applied, the less time hackers have to exploit known vulnerabilities.

Respecting Privacy on the Server Side

  • Differential Privacy
    • Sometimes, it can be valuable to access databases to view statistics around certain fields.
    • However, malicious queries could be used to figure out information about individual users.
    • For example, a combination of gender, zip code, and birthday can identify up to 87% of the US population.
    • By adding noise to these queries, it is possible to foil such attempts while still being informative.
  • Federated Learning
    • For security purposes, certain data should not leave a particular device.
    • However, certain ML models need large amounts of data.
    • To train while respecting privacy, it would be best to train local models and then merge them together off-device.
    • This could also be combined with differential privacy to prevent malicious individuals from inferring information from models stolen while in transit.
  • Opt-In Defaults
    • Users should be informed about data that is being collected as well as exactly what it is being used for.
    • This not only helps preserve privacy, but helps build trust with users.
  • Strong Cybersecurity
    • Data leaks can destroy reputation and user trust.
    • To prevent this, making sure to have robust cybersecurity tools and policies can prevent cyberattacks that would require remediation.

Product Placement in Sports Marketing: Tips and Tricks

Last Updated: August 2, 2026

The Basics of the Niche

Any time a logo is seen next to a professional athlete, the brand behind the logo likely paid for that placement. These logos could be placed on anything from jersey patches and shoes to stadium naming rights and other signage. However, it is not always obvious how this placement is valued. It was my job at MVP to help both brands and sports teams/athletes determine a fair market value for product and logo placements.

What to Keep in Mind

As a Machine Learning Engineer, I formerly managed various computer vision pipelines for many leagues, including:

  • MLB
  • NBA
  • PGA
  • NHL
  • PFL
  • UFL
  • NFL

Regardless of which leagues, teams, and athletes I worked with at the time, there were several common features that correlated very well with the value of a brand placement. These features included visual signals like:

  • Size
  • Orientation
  • Occlusion
  • Motion Blur
  • Digitally-Enhanced vs. Analog Assets
  • Relative Clutter
  • Context of Placement

Size

Intuitively, the larger a logo is, the easier it is for both the human eye and a computer vision model to pick it up. It would additionally get more screen real estate. However, there is increased risk of occlusion and other factors interfering with the recognizability of the logo.

Orientation

Should a logo not be radially-symmetrical, rotating it may require more effort for the human eye to consciously pick it up. Depending on whether object detection or instance segmentation models are being used, this could also interfere with the estimates of screen real estate used. It also could make it more difficult for computer vision models to track it.

Occlusion

For obvious reasons, if something or someone is between the camera and the logo, the logo will not be visible. In cases of partial occlusion, it is important to consider how much of the logo can be occluded before it is difficult to truly recognize.

Motion Blur

As athletes, environment, and camera angles change, this can easily cause motion blur. This motion blur, most obvious in high-speed sports like NASCAR, can make it more difficult to clearly identify a logo. Reduced visual sharpness can make it more difficult to definitively and meaningfully attribute certain regions of the screen to a particular brand.

Digitally-Enhanced vs. Analog Assets

Certain assets, like virtual glass the NHL has been experimenting with or digitally-enhanced dasherboards (DEDs), are made more clear by reducing natural motion blur. Analog assets, however, experience all effects of the camera lens would subject them to.

Relative Clutter

In product placement environments, it is common to have other objects in the scene. These other items could draw attention away from your logo. This is especially true if these other items also have clearly-visible logos.

Context of Placement

What is occurring on screen can be as important as actually getting a logo on screen in the first place. Events that have relatively high stakes or emotion associated with them are more likely to get more viewership per second by orders of magnitude. Because of this, areas of the field/arena that share proximity to the goal are more likely to indirectly bring additional value.

General Advice and Strategy

Even knowing these features, it might not be obvious what to do to optimize your brand/product placement.

  • Make the placement as large as reasonably possible.
    • Viewers are more likely to consciously pick up the brand placement.
    • Has the side benefit of reducing relative clutter.
  • Orientation should have any logos/text placed in a way to be easily read or recognized by the viewer.
    • The amount of brainpower required to recognize a logo is inversely proportional to the number of people who will recognize it.
    • Logos may only be visible for seconds at a time.
  • Move placement as close to the foreground as possible.
    • Limits potential occlusion when the placement is in frame.
    • Can potentially limit blur present in backgrounds in some camera setups.
  • Put placements on subjects of an image/video where possible.
    • Subject tends to have minimal motion blur.
    • Background appears to move behind subject, subjecting it to both motion blur and potential occlusion.
  • Get placements where there is little competition for viewer attention.
    • If eyes are elsewhere, fewer people will notice your placement and make it less valuable.
    • Some of this is unavoidable, as product placement virtually guarantees your content will be onscreen in a way that doesn't feel like an advertisement.
    • Attention is inversely correlated with the number of distinct objects onscreen.
  • Placements should occur near action where emotions run high.
    • These moments are more likely to be re-shared later.
    • More viewers will watch it initially.
    • Video clips with heightened emotion are more likely to be shared more frequently online.

Physical Media Supremacy: Why is Streaming Struggling?

Last Updated: August 11, 2026

What is Physical Media?

The exact format changes based on both the decade and the content. Music and audio had the vinyl record and the CD. Video had the VHS, DVD, and the Blu-ray. Images had raw film. What unites these formats is that once you buy a copy, it stays usable for years with very little effort.

The Rise of Streaming and Online Piracy

Physical media, by virtue of being physical, requires storage space as well as a reader to display the format. Because of this, physical media formats require physical distribution networks and dedicated areas of the house for consumers to maintain access. Streaming offered a legitimate market for digital distribution, often supplemented by online piracy for those willing to use less reputable sources and reputable antivirus. The calculation was simple: streaming services often supplied a larger library than an end user could manage on their own and limited the downside of purchasing/renting bad content. Online piracy, while somewhat riskier due to less reputable suppliers, often acted as a grey/black market that the legitimate streaming services were not willing or able to offer. When combining these in the early years of streaming, it was reasonably affordable to access virtually every movie and song for much less than comparable services.

If Buying isn't Owning, Piracy isn't Stealing

However, a simple format exchange was not the full extent of the story. Streaming fractured and turned from monopolies to oligopolies. Initially, Netflix was synonymous with movie and television streaming, while Spotify dominated the music and audio format. Now there are several streaming services founded with the sole target of breaking up their initial monopoly over streaming content with mixed results. This has led to streaming content becoming increasingly distributed across multiple streaming services and an escalating bidding war over content that is popular with users. As this raised costs and created increasingly complicated licensing, it caused the all-too-common enshittification. Prices rise, advertising becomes prevalent, and content that doesn't have a good return on investment is unceremoniously dumped from the platform. When quality becomes worse, this often leads to users questioning the value proposition of the now-enshittified platform in the first place. If users are receiving poor overall service quality, it is only rational that consumers will reach for alternatives.

Media Preservation

For older content, it is often not obvious who has the rights to distribute, sell, stream, or otherwise provide access. This is doubly accurate for media created/owned by companies that went bankrupt while maintaining rights to content. Similar issues occur thanks to outdated hardware like game consoles that are no longer sold by original manufacturers and related abandonware. Often, this content can be considered classic and culturally relevant. A conundrum arises out of this situation: how do you preserve media for future generations in a way that is respectful of ownership when the original owner cannot speak up? Such legal and moral conundrums often leave a gray area when there is nobody who owns a legitimate copy. When end users have clear legal ownership of a copy of content, each copy essentially becomes a decentralized backup. As the number of copies in the hands of consumers increases, this makes it easier for people to view culturally-relevant media by borrowing a copy. Therefore, physical media will be an indispensable component of media preservation.

Build Better or Die

Streaming initially gained popularity by becoming more convenient than the content rental stores that they eventually replaced (e.g. BlockBuster). However, as streaming services become more expensive and less convenient, this diminishes their cultural dominance and currency. The degraded service will likely result in some sort of equilibrium in which each price hike and advertising-supported tier leads to a measurable impact on piracy, physical media purchases, and profits alike. While companies are simply responding to market forces, it is worth remembering that no business can last for long without a loyal customer base.

Vibe Coding is a Scourge to the Internet

Last Updated: August 27, 2026

What is Vibe Coding?

For those who have not been exposed to the software development industry post-ChatGPT, vibe coding is the practice of generating code with LLMs with little-to-no oversight. Since vibe coding is almost wholly reliant on the LLM beyond prompting, there is very little barrier to entry on the individual. While discussing definitions, it is worth contrasting vibe coding with AI-assisted coding. AI-assisted coding is when a technical individual combines traditional software engineering practices with LLMs to write boilerplate code with clear specifications. In this latter case, the user is often more knowledgeable in best practices and often step in more frequently when LLMs get sidetracked or start hallucinating.

The Appeal of Vibe Coding

For someone non-technical, it is extremely tempting to type an idea into a text box at breakfast and have a first draft of an app by lunch. There is no need to read documentation or learn a programming language. All that would be required is a specific enough prompt and access to a powerful enough model. Since 99% of people who are not professional developers, this can feel incredibly power to many. While programming languages are well-documented, the learning curve can seem daunting to those who do not know where to start.

Monkey's Paw: Hidden Tech Debt

When it comes to anything in engineering, there is a saying:

"Good, Fast, Cheap. Pick any two." - James M. Wallace

Vibe coding selects fast and cheap by default. Non-technical users tend not to have the experience or knowledge to understand this tradeoff. This drop in quality has subtle signs that are easy to miss if you don't know to check. Edge cases can be missed. Cybersecurity measures not explicitly stated may not be implemented. Features requested during a followup collide and overwrite older features. Someone who doesn't know how to code has no hope of correcting these issues when it arises. Technical users may proceed more cautiously when using LLMs to develop code, but human oversight adds additional stability that LLMs cannot offer in their current state.

Cultural Ramifications

There have been some concerning trends in the culture around vibe coding. A lot of non-technical users assume that because AI can output code that it means that human developers are a largely redundant layer. Similar debates have occurred within the artist and author communities as of late, since AI is capable of producing both images and general text. It is equally easy to destroy all three arguments for outright replacing humans with AI in all three of these fields: the knowledge to be good at anything is rarely captured in the raw output itself. Knowledge of a genre and reader psychology can influence a book in a way that cannot be easily represented for AI. Anatomical understanding and an innate understanding of the physics of everyday objects can similarly influence an artist's creative choices in ways that AI models don't consider. Software engineering, by extension, often requires an in-depth lived experience that it is difficult to truly capture in the number of tokens that fit within the average LLM's context window. In many different fields, there are a plethora of unstated assumptions that allow humans with proper training to have a much wider breadth of skills than any algorithm at the time of writing can truly capture.

Spreading the misinformation that humans are no longer needed is also leading to chronic understaffing in many critical roles. Understaffing tends to most noticeably affect entry-level and customer-facing roles, where it is assumed that AI-assisted humans are capable of replacing several unassisted staff. This assumption only works under a very specific set of circumstances:

  • All job responsibilities have been properly documented.
  • AI models can do some or all of these tasks with minimal supervision.
  • The company has high-quality data on how many man-hours are now idle thanks to the AI automating these tasks.
  • AI has a lower failure rate than a comparable human on this task in the vast majority of daily situations.
  • Humans do not need to extend bandwidth to verify/correct AI output.
  • All AI pipelines have strict, automated verification that reduces error rates to below human.
  • In the event of something unusual happening, the AI handles the task as well or better than humans.
  • Whatever hypothetical pipeline is suggested for this is cheaper and/or faster per request than comparable humans.

Many vibe coders tend to not put sufficient thought into these practical concerns. Because of this, it is common to have a flashy vibe coded demo that looks great, but underperforms on real world tasks.

Taking a Stand against Vibe Coding

Once someone has been seduced by the false promises of vibe coding, how can they break free from the bad habits they have learned? It is possible to do this with effort and self-improvement. The following process can help mitigate this:

  1. Understand applications of data structures and algorithms.
    • Many problems novice coders face are similar to problems that have already been solved.
    • Using existing structures usually means less work for a programmer to design and implement from scratch.
    • Several books are available at Systems & Algorithms.
  2. Learning to program without generative AI.
    • It will feel slow and difficult.
    • However, learning to use the tools allow you to fix issues when an LLM fails you.
    • Several books that can help with that in the C/C++ and Python sections of this site.
  3. Getting comfortable with design patterns.
    • Code written by LLMs mostly meets specs, but is often laid out poorly.
    • Learning common design patterns makes it easier to maintain a codebase.
    • A list of resources can be found at Systems & Algorithms.
