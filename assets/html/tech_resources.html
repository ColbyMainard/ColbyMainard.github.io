Cybersecurity

Certifications

Name Description
Certified Information Systems Security Professional (CISSP) Assesses knowledge across eight domains of information security, and requires 5 years experience in cybersecurity.
Certified Information Systems Auditor (CISA) Checks governance of IT systems.
CompTIA Security+ A great way to demonstrate core security knowledge for those new in the industry.
Certified Ethical Hacker (CEH) Teaches how to think like a hacker and defend against real-world cyber threats.
Certified Information Security Manager (CISM) Mainly focused on making sure managers can apply proper governance and risk assessment.

Books

Title Author Benefits
Open Source Intelligence Techniques Michael Bazzell Resources for ethical sleuthing on individuals/organizations over the internet. Goes over things like:
  • Social Media
  • Search Engines
  • Email Addresses
  • Usernames
  • Online Communities
  • People Search Engines
  • Phone Numbers
  • Online Maps

  • Images

  • Government/Business Records
  • Virtual Currencies
  • Advanced Linux Tools
  • Data Breaches/Leaks
  • Methodology/Workflow
  • Documentation/Reporting
  • Policy
  • Ethics
  • Development
Extreme Privacy Michael Bazzell For those who either fear for their safety online or read the author's work on available OSINT technologies and are feeling paranoid. It is designed as a guide to make tracing your digital life back to your physical life as difficult as possible.
Cryptography Algorithms Massimo Bertaccini This book serves as an introduction to real-world algorithms used in blockchain, quantum cryptography, zero-knowledge protocols, and homomorphic encryption. For those looking to get a better understanding of cryptography, this is a good start.
The Ghidra Book Chris Eagle and Kara Nance Especially useful for malware analysis, this book is a guide for utilizing Ghidra to decompile and analyze binaries.
Black Hat Python Justin Seitz and Tim Arnold This book serves as a good starting point to develop your own tools as a penetration tester in cybersecurity. As it contains code examples that could easily be turned into malware by nefarious users, it is important to know that this is for educational purposes only.
Bug Bounty Bootcamp Vickie Li While bug bounties are a necessary part of the cybersecurity ecosystem, it can be difficult for new penetration testers to start. This book serves as a guide to starting on web applications.
Ethical Hacking Daniel G. Graham This book serves as a good in-depth guide to ethical hacking and penetration testing, as well as related technologies.
Metasploit David Kennedy, Jim O'Gorman, Devon Kearns, and Mati Aharoni Metasploit is a very useful tool for using known exploits. This book serves as a solid guide for utilizing this tool in the real world.
Practical Binary Analysis Dennis Andriesse ELF (Linux binaries) and PE (Windows) binaries are very complicated. However, many files both legitimate and not are in these formats. This book is a good guide to exploring these files yourself.
NMAP Network Scanning Gordon "Fyodor" Lyon Written by NMAP's creator, this book is a guide to network scanning.
Hacking: The Art of Exploration Jon Erickson This book serves as a good reference for hacking techniques on local machines complete with examples.
Machine Learning & Security Clarence Chio and David Freeman Machine learning can be used for many areas, like:
  • Anomaly detection
    • Fraud
    • Breaches
    • Impending system failure
    • Extracting useful information from binaries
    • Understanding threats to machine learning solutions
Social Engineering: The Science of Human Hacking Christopher Hadnagy This book is a good guide to social engineering attacks.
Blue Team Field Manual Alan White and Ben Clark This book is a compilation of useful defensive commands for Linux and Windows command line.
Purple Team Field Manual Tim Bryant This book serves as a compilation of useful defensive and offensive CLI commands to help both penetration testers and network defenders.
Red Team Field Manual Ben Clark This book serves as a compilation of useful offensive CLI commands for penetration testers.
Red Team Field Manual v2 Ben Clark and Nick Downer This book is a revised and expanded version of the original by a similar name.
Hash Crack Password Cracking Manual 3.0 Netmux LLC This book is the best guide I have found for cracking hashed passwords.
Linux Field Manual Tim Bryant This book is a brief guide to Linux command line and internals.
Modern Cryptography and Elliptic Curves: A Beginner's Guide Thomas R Shemanske This book serves as a solid background to the mathematical underpinning of cryptography.
Digital Media Steganography: Principles, Algorithms and Advances Mahmoud Hassaballah This book serves as a guide to hiding information in modern media formats.
Advanced Penetration Testing: Hacking the World's Most Secure Networks Wil Allsopp This book is a guide to how advanced persistent threats operate in the real world and how they attack organizations.
Kali Linux - An Ethical Hacker's Cookbook Himanshu Sharma This book goes over utilizing Kali Linux in real-world penetration testing engagements.
Introduction to Computer Security Michael T. Goodrich and Roberto Tamassia This book is a good survey of both theoretical and practical cybersecurity topics for both internet and local applications.
The Giant Black Book of Computer Viruses Mark Ludwig Most books don't provide low-level assembly and implementations of advanced binary manipulation. I would recommend this book to those who are interested in that.
Black Mass vx-underground This book goes over interesting viruses and related techniques, like:
  • Fractionated Cavity Loaders
  • Hardware Breakpoints for Malware
  • File Minisystem Callbacks
  • Antivirus Memory Scanning
  • RedKing HiveMind
Black Mass: Volume 2 vx-underground A sequel to Black Mass, this book goes over interesting viruses and related techniques, like:
  • Hacking WinRE Reinstaller
  • Decrypting PCRYPT
  • Infecting ELF binaries
  • Diskless Persistence
  • Secureboot tampering

Artificial Intelligence

Books

Title Author Benefits
Neural Networks and Deep Learning Charu C Aggarwal I found it covers reinforcement learning, RNNs, and other information not covered in most other books here.
Hands-On Machine Learning with Scikit-Learn & Tensorflow Aurelien Geron This book is a good introduction to useful ML packages, compete with real-world examples and code.
Mining of Massive Datasets Jure Leskovec, Anand Rajaraman, and Jeffrey David Ullman This book covers a variety of interesting topics and tools, like:
  • PySpark
  • Market Basket Analysis
  • Recommendation Systems
  • k-Anonymity
  • Differential Privacy
Learning from Data Yaser S. Abu-Mostafa, Malik Magdon-Ismail, and Hsuan-Tien Lin Many need a practical start to MLOps, this book covers some crucial best practices, including practical training and testing advice. I found this book a good baseline to build upon.
Introduction to Machine Learning Ethem Alpaydin This book is a good guide to the math underpinning a variety of machine learning models.
Deep Learning with Python Francois Chollet For those looking for a deep learning book with examples, this is a good read for advanced neural network architectures and technologies.
Artificial Intelligence: A Modern Approach Stuart Russell and Peter Norvig This book is a good base for learning the history of AI and underpinnings of AI that can be more deterministic.
Deep Learning for Coders with fastai and PyTorch Jeremy Howard and Sylvian Gugger This book can provide a background in PyTorch to get started quickly.
Machine Learning Solutions Architect Handbook David Ping I would recommend this book for learning how to design artificial intelligence pipeline architectures.
Designing Machine Learning Systems Chip Huyen Data engineering and tracking success within an ML pipeline is essential, and this was really helpful for me when building that out.
Delta Lake: Up and Running Bennie Haelen and Dan Davis Data has to come from somewhere. When using Delta Lake for data lakehousing, I would recommend this book as a starter.
Apache Iceberg: The Definitive Guide Tomer Shiran, Jason Hughes, Alex Merced Similar to Delta Lake: Up and Running, this is a robust guide to Apache Iceberg for data lakehousing.

C/C++

Books

Title Author Benefits
C++ Primer Stanley B. Lippman, Josee Lajoie, and Barbara E. Moo C++ can be a difficult language to approach for beginners. This book is a good guide to learn the features of the language from simple to advanced
Data Structures & Algorithms in C++ Michael T. Goodrich, Roberto Tamassia, David Mount One of the most important knowledge a programmer can have is picking and implementing the best data structures and algorithms for a job. This book is a good guide of how to do that.
Programming Principles and Practice Using C++ Bjarne Stroustrup For beginners, I would recommend using this book for easy projects to get comfortable with C++ using basic projects.
Effective Modern C++ Scott Meyers This book is a great guide for patterns in C++.
Mastering the C++17 STL Arthur O'Dwyer While the STL has received several upgrades since it was written, this book is a good reference for useful patterns in C++.
Hands-On GPU-Accelerated Computer Vision with OpenCV and CUDA Bhaumik Vaidya With computer vision, many are concerned about the large computational load. This book is a good resource for improving computer vision pipeline performance.
Learning Boost C++ Libraries Arindam Mukherjee Boost is a common library for C++ that isn't used in the STL. This book is a good guide to utilizing Boost effectively.

Books

Title Author Benefits
